# Enterprise Network Design Documentation

This folder contains the complete technical report for my Cisco Packet Tracer project.

The project connects:
- Hyderabad Head Office
- Chennai Branch
- Bangalore Branch
- ISP Network

Technologies:
- VLAN and Trunking
- Inter-VLAN Routing
- OSPF
- DHCP and DHCP Relay
- NAT/PAT
- Access Control Lists
- SSH Remote Management
