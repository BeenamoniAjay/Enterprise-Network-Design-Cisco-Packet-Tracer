# Enterprise Network Design – Cisco Packet Tracer

## Project Overview
Designed and implemented a multi-branch enterprise network using Cisco Packet Tracer, connecting a Hyderabad Head Office with Chennai and Bangalore branch offices through an ISP network.

## Network Topology
- Hyderabad Head Office
- Chennai Branch Office
- Bangalore Branch Office
- ISP Network

## Network Topology Diagram

![Enterprise Network Topology](Screenshots/Final%20Topology.jpeg)

## Technologies Implemented
- Cisco Routers and Layer 2 Switches
- VLANs and 802.1Q Trunking
- Inter-VLAN Routing
- OSPF Dynamic Routing
- DHCP and DHCP Relay
- NAT/PAT
- Extended Access Control Lists (ACLs)
- SSH Remote Management
- Network Connectivity Testing

## Project Verification
- DHCP address assignment verified
- Inter-branch routing tested
- NAT translations verified
- External connectivity to 8.8.8.8 tested
- ACL security behavior tested
